# LGPD

- Consentimento explícito no formulário de agendamento (checkbox + link da política de privacidade).
- Coletar apenas dados necessários no agendamento (nome, telefone, e-mail).
- Acesso por papel; auditoria de acesso a receitas.
- Permitir exportar e anonimizar dados de um paciente a pedido.
- Backup automático do Firestore e política de retenção definida pelo consultório.
- Texto de política de privacidade deve ser revisado por profissional jurídico.
